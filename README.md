## 📂 Project Structure
- `preprocessing/`: Data cleaning and preparation.
- `training/` & `corporate_reorganization/`: Model fine-tuning scripts.
- `evaluation/` & `corporate_reorganization/test_results`: Benchmarking and performance metrics.
- `corporate_reorganization/`: Core dataset logic.

## 🚀 Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Configure environment (Cohere API or other Reranking vendor): Setup `.env` file.
3. Run training or evaluation via the respective directories.
